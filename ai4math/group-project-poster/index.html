How to compile

Put all three files (.tex, .sty, XMU2.png) in the same folder, then:

pdflatex group-project-poster-template.tex

This produces a single-page A0 portrait PDF. If you use Overleaf, create a new project and upload all three files.

What to put on the poster

The template is pre-structured into the sections we expect. Do not remove sections; do fill them in.

  • Header: presentation title, group number, group members.
  • Abstract (150–200 words).
  • Question and Motivation — the small question the project studies.
  • Method / Workflow — with a diagram if useful.
  • Preliminary Results — a table, chart, or concrete numbers.
  • Representative Example — one worked example end-to-end.
  • Error Analysis and Limitations — required.
  • AI Use Statement — what tools, for what, how checked.
  • References — 6–10 items.
